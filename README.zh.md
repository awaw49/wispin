# Wispin

**中文** · [English](README.md)

Android 上的 iOS 定位修改工具。Wispin 把你的安卓手机变成一个 MFi GPS 配件，
通过蓝牙向 iPhone 推送 NMEA 定位——不越狱、不插线、不需要电脑。

> [!IMPORTANT]
> **iOS 26 及以上**：苹果调整了定位融合算法与缓存。连接成功后需要先
> [刷新一次定位缓存](#ios-定位缓存刷新)，iPhone 才会采纳外部定位源。

## 功能

- **单点模式**：地图选点或手输坐标，iPhone 直接跳过去。
- **路径模式**：地图上画折线或导入 GPX 文件，按设定速度沿路径移动，可循环。
- **GPX 时间回放**：带 `<time>` 的轨迹按录制节奏回放，停留、快慢段原样还原。
- **实时换点**：会话运行中直接点地图换点或改路径，立刻生效，无需重连。
- **地图**：OpenStreetMap（WGS-84）与高德（GCJ-02）双底图，坐标自动转换，支持收藏点。
- **NMEA 参数**：GGA/RMC 语句，可调定位质量、卫星数、速度、航向、海拔、精度。
- **随机化**：可选位置抖动、精度与海拔范围随机。
- **配件身份**：每次会话可轮换广播的配件名与序列号。

## 环境要求

- Android 8.0+ 带蓝牙的手机。
- 一台在系统蓝牙设置中与安卓手机配对过的 iPhone。
- MFi 配件身份文件（见下）。没有它们链路能连上但认证过不了，不会推定位。

## 快速上手

1. **安装** Releases 里的 APK（或源码自行构建）。
2. **导入 MFi 身份**：打开 App，导入 `identity.pk8` 和 `certificate.p7b`（一次即可）。
3. **配对**：在 iPhone「设置 → 蓝牙」里与安卓手机配对。
4. **选目标**：切「单点」或「路径」，点地图放点，按开始按钮。
5. 看状态栏——显示已认证、帧计数增长即表示 iPhone 已订阅并在接收定位。

## iOS 定位缓存刷新

iOS 26+ 只在融合刷新时刻采纳外部定位源。连上后蓝点不动，按以下步骤：

1. **关掉** Wi-Fi、蜂窝数据、定位服务，等 10 秒，开回定位服务——Wi-Fi 先别开。
2. 打开**地图**，确认蓝点落在目标坐标。
3. 开 Wi-Fi，等定位稳定后再开蜂窝数据。

仍不生效：保持无线电关闭状态重启 iPhone，再从第 2 步开始。

## 路径模式说明

- **循环**把路径当成闭合回路：位置沿末点→起点的闭合边（地图上已画出）回到起点，
  全程连续、环回处无瞬移。
- **已走计数**只统计 iPhone 实际订阅期间送达的里程，没接收时不空跑。

## MFi 身份

完成 MFi 认证需要合法获得的配件凭证。本仓库不包含私钥与证书：

```text
identity.pk8       # PKCS#8 DER P-256 私钥
certificate.p7b    # 配件证书链
```

**不要把密钥、证书或含真实设备信息的日志提交到仓库。**

## 常见问题

| 现象 | 排查 |
| --- | --- |
| 列表里没有 iPhone | 系统蓝牙是否已配对、iPhone 蓝牙是否开 |
| 连接失败/断连 | 设备 SDP 是否广播 iAP2 UUID；删除配对重来 |
| 已认证但帧数不涨 | 等 iOS 发 0xFFFA 订阅；iPhone 地图保持前台 |
| 蓝点不动 | 执行上面的[缓存刷新](#ios-定位缓存刷新)步骤 |
| 蓝点卡在路径终点 | 勾选**循环**，路径几何闭环 |
| MFi 认证失败 | `identity.pk8` / `certificate.p7b` 缺失或不匹配 |
